Error: Cannot connect to React client. Make sure the dev server is running on port 5173.

Setup Instructions:

  1. Start the server: cd server && cargo run
  2. Start the React client: cd clients/react && pnpm dev
  3. Open Developer Tools (F12) and go to the Console tab
  4. Navigate to Lobbies → Create a Tic-Tac-Toe lobby → Join with two players
  5. Start the game and make moves while watching the console

🔍 What to look for in the console:

  • Entity definitions: Look for entityDefs in the game state
  • Zone contents: Check zones.board.contents for cell data
  • Render calls: Look for "Rendering cell" logs
  • WebSocket messages: Monitor patch operations
  • State updates: Watch for state changes after moves

Useful console commands:

// Get current game state
const state = window.__BLUEFELT_STATE__;
console.log('Entity definitions:', state?.game?.entityDefs);
console.log('Board contents:', state?.game?.zones?.board?.contents);
console.log('Current player:', state?.game?.currentPlayer);

// Check specific cell
const cell = state?.game?.zones?.board?.contents?.[0];
console.log('First cell:', cell);
