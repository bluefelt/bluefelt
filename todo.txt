There is another new case in the game Three Men's Morris, which is the pattern of first selecting an entity and then moving it. I want to use phases to handle this. One phase in a set could have the prompt to "select a token" and then the affordances would appear around the selectable tokens. Then that would transition to a new phase where the prompt is "place the piece". Now the affordances show spaces the piece could be placed. I think we'll have a lot of situations like this in future games, so building in proper handling would be time well spent. The other aspect is that it should be possible to "cancel" after you select a piece. This sort of action is not a commitment, meaning you should be able to select a piece, change your mind, then select another piece. Only placing the piece is a commitment. So we need to find a way in the UI to allow a user to cancel if they decide not to move a certain piece.
